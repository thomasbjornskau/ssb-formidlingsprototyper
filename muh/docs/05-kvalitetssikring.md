# Kvalitetssikring: Utenrikshandel med varer (muh)

Denne listen erstatter de tidligere listene i `01-innsikt.md` (spørsmål og hull), `02-kvalitetssikring.md`, `03-kildekart.md` (hull og hindre) og `04-byggenotat.md` (nye valg). Tidligere nummer står i kolonnen «Grunnlag», slik at sporet kan følges.

**Prototypen:** https://thomasbjornskau.github.io/ssb-formidlingsprototyper/muh/index.html (versjon 0.2)

Tallene i prototypen er hentet fra statistikkbanken med `hent_data.py` 04.11.2026 og kontrollert ved hvert bygg (elleve sum- og metodekontroller, se `04-byggenotat.md`). Det som skal kontrolleres her, er tolkninger, avgrensninger og formuleringer.
